Paint Studio - アプリ紹介文 (日本語)
================================================================================

【Paint Studio】
軽量・オフライン動作の Windows デスクトップお絵描きアプリ

Paint Studio は、思いついたときにサッと開いてサクッと描ける、
シンプルさにこだわったペイントツールです。インストール不要の単体
exe ファイルとして配布しており、ネット接続や会員登録も一切不要。
広告も入っていません。

■ 主な機能
・基本ツール：鉛筆、消しゴム、ブラシ、塗りつぶし、スポイト
・図形ツール：直線、四角形、角丸四角形、楕円（線のみ／塗りつぶし／
  両方を切り替え可能）
・テキストツール：配置後も再選択して文字・フォントサイズ・色を
  何度でも編集可能（非破壊編集）
・図形の再選択編集：配置後も形・色・移動が自由自在
・選択範囲：矩形選択、投げなわ選択、自動選択（マジックワンド）
・選択範囲やテキスト・図形はドラッグでも矢印キー（1px／Shift+10px）
  でも移動可能
・クリップボードからの貼り付けは下の絵を消さずに配置
・自由変形（4隅パース変形＋回転＋ピボット移動）
・ポイントワープ（輪郭点をつかんで自由に歪ませるパペットワープ）
・端まで描くとキャンバスが自動で広がる無限キャンバス
・グリッド表示・スナップ機能
・Undo / Redo 対応
・PNG・JPEG・BMP での書き出しに対応
・日本語 / English 表示切り替え対応

■ 動作環境
・Windows 10 / 11 (64bit)
・インストール不要、exe をダブルクリックするだけで起動

■ こんな方におすすめ
・メモ代わりにサッと図を描きたい
・スクリーンショットに手早く注釈を入れたい
・軽いお絵描きツールを探している
・広告なし・オフラインで完結するツールが欲しい

Paint Studio は個人開発のフリーウェアです。気に入っていただけたら、
開発の励みになりますのでぜひ一言感想をいただけると嬉しいです。

Paint Studio - App Introduction (English)
================================================================================

【Paint Studio】
A lightweight, offline Windows desktop paint & sketch app

Paint Studio is a simple, no-frills paint tool you can open in a
heartbeat and start drawing right away. It ships as a single portable
.exe with no installation required, no internet connection needed, no
account/sign-up, and no ads.

■ Key Features
- Core tools: pencil, eraser, brush, fill bucket, color picker
- Shape tools: line, rectangle, rounded rectangle, ellipse (toggle
  between outline / filled / both)
- Text tool with non-destructive editing — reopen any placed text at
  any time to change the wording, font size, or color
- Shapes are also non-destructively editable — reshape, recolor, and
  move them freely after placing
- Selections: rectangle select, lasso select, magic wand (auto-select)
- Selections, text, and shapes can be moved by dragging or with the
  arrow keys (1px, hold Shift for 10px)
- Pasting from the clipboard doesn't erase the artwork underneath
- Free Transform (4-corner perspective warp + rotation + pivot)
- Point Warp (grab points along a shape's outline and warp it freely,
  puppet-warp style)
- Infinite, auto-expanding canvas — keep drawing past the edge and the
  canvas grows to fit
- Grid display and snap-to-grid
- Full undo / redo history
- Export to PNG, JPEG, or BMP
- Switchable Japanese / English UI

■ System Requirements
- Windows 10 / 11 (64-bit)
- No installation needed — just double-click the .exe to run

■ Who it's for
- Anyone who wants to jot down a quick sketch or diagram
- Quickly annotating screenshots
- Looking for a lightweight paint tool without the bloat
- Prefers an ad-free, fully offline tool

Paint Studio is an independently developed freeware app. If you enjoy
using it, a quick note of feedback is always appreciated and helps
keep development going!
